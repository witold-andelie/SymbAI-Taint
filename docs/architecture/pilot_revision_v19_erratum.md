# V19 audit erratum: native edge-label selection

Recorded on 12 November 2026 after the original WSL capture and before correction of
the live validator. The original v19 specification and captured source/input/payload
snapshots remain unchanged. RQ1/RQ2, panels, model, original TYGR source, runtime inputs
and measurements remain unchanged.

The original specification and validator incorrectly described `encode_edge_label` as
selecting the last sorted label. AST inspection of the frozen upstream `preproc.py`
shows that its `return` is **inside** the `for` loop. The native function selects the
**first sorted label**. It then uses the saved known/reduced/unknown mapping and adds
`num_all_ops` for the inverse direction. The original worker calls that native function
directly; its observed IDs were never generated by the incorrect validator formula.

The returned WSL matrix has 103 native edges, **all single-label**. First and last are
therefore identical on every observed edge, so this correction changes no recorded
native tensor value, ID, status, domain finding or readout group. It does invalidate the
old validator's claimed coverage of multi-label inputs. Passing its old unit fixtures
did not prove agreement with the upstream function on that branch.

The live validator and fabricated multi-label tests are corrected. A regression test
isolates the actual upstream pure encoder function from its AST and checks its output
without importing TYGR or a framework. The independent audit also checks source control
flow and recomputes every observed ID. The original validator is retained in the WSL
source snapshot at SHA-256
`20f9ad6c2eec36f112683a0bb32596059bbf0337aa83a768699fd03968d55436`;
the audit distinguishes historical source identity from this documented live correction.

The original v19 specification and preflight evidence are historical records. Their
last-label wording is superseded by this erratum. Future capture uses the corrected
validator; no new capture is required solely to correct this all-single-label matrix.
No historical edge usage, model forward behavior, general input compatibility, v17
projection or neural benefit follows from this audit.
