# Development revision v16: information readiness and trace-cost gate

Declared on 12 November 2026 after inspecting v15 outcomes/costs and the existing TYGR
adapter. This is a retrospective feasibility diagnostic, not a preregistered validation
study. Freeze these rules before implementing/aggregating this diagnostic. Retain v15
and all older runtime source/specifications and measurements unchanged.

## Fixed inputs and scope

Use the complete audited v15 WSL 18+3 record set and its three copied ELF/query contracts.
Recompute its pure evaluation before deriving any cost statistic. Compare the binary
hashes against only the three frozen genuine raw exports and six bindings in the retained
v12 location-correspondence panel. Do not pool the two panels or substitute names for
binary identities. Do not execute a model, property operation, graph generator or mapper.
Read no new program and create no new variant, DWARF section, package, prediction or query.

Inspect each binary's ELF section metadata without modifying it. Record absence of debug
metadata and exact matching frozen export/correspondence coverage independently. Neither
a matching hash nor debug metadata alone establishes a usable general mapping. Inspect
and hash the adapter/upstream source evidence: the current export uses the DWARF locator;
the incomplete upstream prediction branch drops register variables, confuses VEX offsets
with DWARF register numbers, and the action summaries use block addresses and overwrite
register identities. These are current-interface limitations, not an impossibility theorem
for TYGR. No fabricated or zero-filled type view can stand in for unavailable predictions.

## Retrospective trace-cost model

For each of the nine fixed-cascade traces, identify the final freshly decisive operation.
In a deliberately optimistic deletion model, remove every preceding unknown attempt at
its recorded `elapsed_seconds`, while keeping the final attempt and all other parent
costs fixed. Report original charge, unknown-attempt sum, retained charge, per-query
vectors and aggregate descriptive values. Validate finite nonnegative clocks, phase sums,
the complete fixed sequence and matrix through the v15 evaluator. Wrong, failed, late,
incomplete or reference-blocked data cannot silently supply a headroom estimate.

This is a revealed-outcome oracle computed offline; it is never an online feature or
deployable policy. It measures only deletable time in the frozen traces. Imports/caches
may be shared inside a trace, and deleting an operation can move initialization cost to
the next one. Changed order, extra operations or a different checker can alter timings.
Consequently this is not an unconditional real-time upper bound or a measured speedup.
Within this explicit fixed-trace model, an added information/selection cost must be less
than the deleted cost to yield a net saving. No cost model is trained.

Keep the historical v5 cold-acquisition profile as separate context only: it concerns a
different binary and locator, and supplies no acquisition time estimate for these v15
inputs. Never divide its cost into the v15 trace statistic to claim a measured slowdown,
warm-service result or impossibility of neural benefit. No type-aware schedule is run.

## Deliverables and decision

Implement a pure trace-cost function and a read-only-input CLI with immutable input/source
snapshots, integrity rechecks and a complete three-query availability report. Test the
accounting and identity boundaries. Record forbidden runtime imports, observed diagnostic
duration and all excluded historical work without calling the offline duration a deployment
budget. Update the OPM view, architecture, evidence and decision gate. All artifacts/cache
remain on D. No WSL experiment is required; the main agent can audit the existing files.

If there is no intersection of complementary-operation queries and genuine mapped type
exports, record that C/D is currently unavailable, not a negative neural-value result.
Before undertaking a register/value-node bridge, require explicit instruction/read-write/
width/overwrite provenance and a plausible incremental information/cost mechanism beyond
fixed cascading and structural load/cardinality cues. This gate does not establish novelty,
generalization, native evidence or journal readiness. RQ1/RQ2 and frozen A-D remain unchanged.
